SITE MENY MENDONÇA — pacote limpo (layout novo como página principal)
=====================================================================

Estrutura
---------
public/                     -> o que o Netlify publica (netlify.toml: publish = "public")
  index.html                -> PÁGINA PRINCIPAL (layout estilo feed):
                               #inicio  Para você     #videos  Destaques (YouTube/TikTok)
                               #momentos Momentos      #eventos Agenda (Google Agenda)
                               #perfil  Sobre mim      #contato Redes + formulário
                               #musicas Músicas        #musica/<id> link direto de uma música
                               Links antigos (#about, #agenda, #contact, #portfolio, #blog)
                               continuam funcionando.
  admin.html                -> painel admin (Netlify Identity). Abas: Início, Sobre
                               (com data de nascimento), Momentos, TikTok, Músicas, Redes sociais,
                               Agenda, Aparência, Curtidas
  offline.html, sw.js, manifest.json -> PWA (sw.js atualizado p/ v3)
  assets/images/            -> só as imagens usadas
  assets/js/temas.js        -> temas de cores (usado pelo site e pelo painel)
  assets/js/redes.js        -> catálogo das redes sociais (usado pelo site e pelo painel)
netlify/functions/          -> 18 Netlify Functions usadas pelo site e pelo admin
                               (novas: musicas-api, musica-buscar, curtidas-api, fontes-api,
                               agenda-api, admin-check)
netlify/lib/auth.js         -> quem é admin do painel (ver "Segurança do login")
netlify/lib/agenda.js       -> leitura do Google Agenda (site e painel)
netlify/lib/feeds.js        -> rotina de atualização dos vídeos (usada pelo feeds-update
                               agendado e pelo botão "Buscar vídeos agora" do painel)
netlify.toml                -> build, agendamento do feeds-update (a cada hora),
                               redirects /admin, /login e /feed.html -> /
package.json / package-lock.json -> dependências das functions
.env.example                -> variáveis de ambiente necessárias (preencha no .env
                               local e no painel do Netlify)

Como rodar localmente
---------------------
1) npm install
2) copie .env.example para .env e preencha
3) npx netlify dev   ->  http://localhost:8888
(Live Server do VS Code NÃO roda as functions.)

⚠️ CURTIDAS — RECURSO REVERSÍVEL (v8)
-------------------------------------
O coração dos posts agora é contado no servidor (function curtidas-api) e
o número aparece embaixo dele; o painel tem a aba "Curtidas" com o ranking.

Travas de custo já ativas:
  - no máximo CURTIDAS_LIMITE_DIA gravações por dia (padrão 3000);
  - no máximo 20 curtidas a cada 10 min por conexão;
  - 1 curtida por item por conexão (guarda só um código embaralhado, não o IP);
  - a leitura das contagens fica 30s em cache no CDN do Netlify.

COMO VOLTAR ATRÁS (se houver gasto excessivo ou abuso):
  1) Mais rápido: painel > aba Curtidas > desmarcar "Curtidas ativas" > Salvar.
     O site para de contar em até 1 minuto; o coração volta a ficar só no
     navegador de cada visitante (como era antes).
  2) Pelo Netlify: Environment variables > CURTIDAS_DESATIVADAS = 1 > novo deploy.
  3) Remoção total: apagar netlify/functions/curtidas-api.js e fazer deploy.
     O site continua funcionando normalmente sem ela.
  Os dados ficam no Netlify Blobs, store "curtidas" (podem ser apagados no
  painel do Netlify em Blobs, se quiser zerar).

Redes sociais pelo painel (v10)
-------------------------------
- Aba "Redes sociais" do painel: YouTube, TikTok, Instagram, Facebook, Kwai,
  X, Threads, WhatsApp, Telegram, Spotify, Twitch, Discord ou outro site.
  Escreva o @ e o link é montado sozinho (ou cole o link). Dá para ocultar,
  reordenar (↑ ↓), remover e adicionar (até 15). O painel só aceita links
  https e avisa quando o link não parece ser da rede escolhida.
- Os links aparecem no site em "Me acompanhe", no botão "Seguir" e na página
  de contato. Ficam salvos junto do conteúdo (conteudo-api, campo "redes").
  Sem nada salvo, o site usa os três links de antes (reserva em redes.js).
- "Link da live": em branco = live do TikTok cadastrado. Todos os botões
  "AO VIVO" usam esse link. O AVISO de que está ao vivo continua vindo do
  monitor de lives (tiktok-live-97o2.onrender.com), configurado à parte.
- "Origem dos vídeos automáticos": canal do YouTube (@, link ou ID UC...) e
  RSS do TikTok. O painel testa antes de salvar (Netlify Blobs, store
  "config", chave "fontes"). Botão "Buscar vídeos agora" atualiza na hora.
  Se uma fonte falhar, a lista anterior é mantida (não apaga os vídeos).
  As variáveis YOUTUBE_ID e TIKTOK_URL_RSS viraram RESERVA: só valem se o
  campo do painel estiver em branco.

Segurança do login (v11)
------------------------
O login é o Netlify Identity (a senha fica com o Netlify, nunca passa pelo
nosso código). O que foi reforçado:
- Só ADMIN entra no painel e salva dados. Admin = e-mail na variável
  ADMIN_EMAILS (separados por vírgula) OU conta com a função "admin" no
  Identity. Qualquer outra conta é recusada no painel E nas functions.
  >>> FAÇA ISTO NO NETLIFY: crie ADMIN_EMAILS com o seu e-mail e faça novo
  deploy. Enquanto ela estiver vazia, o painel mostra um aviso amarelo e
  qualquer conta do Identity é aceita (como era antes).
- Netlify > Site configuration > Identity > Registration: deixe "Invite only"
  (ninguém cria conta sozinho). Em "External providers", deixe desligado o
  que você não usa.
- Senha: use uma senha longa e única; o Netlify cuida do limite de
  tentativas. O painel sai sozinho depois de 60 minutos sem uso.
- Upload de imagens: só aceita JPG, PNG, WEBP e GIF de verdade (confere o
  arquivo) e até 5 MB. As imagens são servidas com proteção para nunca
  virarem página/script.
- Links de imagem e momentos: só do próprio site ou https.
- Cabeçalhos (netlify.toml): o painel não pode ser aberto dentro de outro
  site, não fica em cache e não aparece no Google; o site todo ganhou
  nosniff, Referrer-Policy e Permissions-Policy.
- Links de convite/recuperação de senha dos e-mails do Netlify continuam
  indo para /admin.html.
