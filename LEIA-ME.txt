SITE MENY MENDONÇA — pacote limpo (layout novo como página principal)
=====================================================================

Estrutura
---------
public/                     -> o que o Netlify publica (netlify.toml: publish = "public")
  index.html                -> PÁGINA PRINCIPAL (layout estilo feed):
                               #inicio  Para você     #videos  Destaques (YouTube/TikTok)
                               #momentos Momentos      #eventos Agenda (Google Agenda)
                               #perfil  Sobre mim      #contato Redes + formulário
                               #musicas Músicas        #musica/<id> link direto de uma música
                               Links antigos (#about, #agenda, #contact, #portfolio, #blog)
                               continuam funcionando.
  admin.html                -> painel admin (Netlify Identity). Abas: Início, Sobre
                               (com data de nascimento), Momentos, TikTok, Músicas, Aparência
  offline.html, sw.js, manifest.json -> PWA (sw.js atualizado p/ v3)
  assets/images/            -> só as imagens usadas
  assets/js/temas.js        -> temas de cores (usado pelo site e pelo painel)
netlify/functions/          -> 14 Netlify Functions usadas pelo site e pelo admin
                               (novas: musicas-api, musica-buscar)
netlify.toml                -> build, agendamento do feeds-update (a cada hora),
                               redirects /admin, /login e /feed.html -> /
package.json / package-lock.json -> dependências das functions
.env.example                -> variáveis de ambiente necessárias (preencha no .env
                               local e no painel do Netlify)

Como rodar localmente
---------------------
1) npm install
2) copie .env.example para .env e preencha
3) npx netlify dev   ->  http://localhost:8888
(Live Server do VS Code NÃO roda as functions.)

Novidades (v7)
--------------
- Data de nascimento editável no painel (aba Sobre). Fica guardada só no
  servidor (Netlify Blobs, store "config"); o site recebe apenas a idade.
  Opção "não mostrar a idade". IDADE_NASC continua valendo como reserva.
- Temas: aba Aparência do painel (Esmeralda, Noite roxa, Pôr do sol, Oceano,
  Dourado, Claro + cor de destaque personalizada com aviso de contraste).
- Músicas: aba Músicas do painel com busca automática de links. Sem chave,
  usa Deezer e Apple Music (links exatos) + páginas de busca para Spotify,
  YouTube, YouTube Music e Amazon. O Odesli (song.link) encerrou o acesso
  gratuito sem chave em set/2026; se um dia você tiver uma ODESLI_API_KEY,
  basta configurá-la no Netlify que a busca passa a usar o Odesli.
